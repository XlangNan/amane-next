# 配置指南

Amane 的配置分为两层:

- **环境变量** — 进程启动时读取, 修改后需重启
- **应用配置** — Web 界面「设置」页面, 实时生效

## 环境变量

| 键 | Docker 默认 | 桌面默认 | 说明 |
| ---------- | -------- | -------- | ------ |
| `AMANE_HOST` | `0.0.0.0` | `127.0.0.1` | 监听地址; 桌面默认只接受本机连接 |
| `AMANE_PORT` | `8000` | `18000` | API 监听端口 |
| `AMANE_DATA_DIR` | `/data` | 系统应用数据目录 | 数据库、资源与配置的存放位置; 修改后不会迁移已有数据 |
| `AMANE_LOG_DIR` | `/data/logs` | 数据目录下的 `logs` | 日志输出位置 |
| `AMANE_TOKEN` | (自动生成) | (自动生成) | API Token; `off` 关闭鉴权 |
| `AMANE_SAFE_DIRS` | (自动推导) | `ALLOW_ALL` | 文件浏览器与库路径的边界目录, 逗号分隔; `ALLOW_ALL` 关闭校验 |

桌面版会读取固定位置的配置文件以设置环境变量, 文件位于:

- macOS `~/Library/Application Support/Amane/desktop.env`
- Windows `%LOCALAPPDATA%\Amane\desktop.env`

可点击菜单中的「打开设置文件」进行编辑, 需重启服务器才能生效.

### 数据目录结构

```
data/
├── amane.db          SQLite 数据库
├── token             API Token (自动生成)
├── translations.db   LLM 翻译缓存
├── resources/        下载的图片、预告片等资源
├── agent/            AI 助理会话数据
├── plugins/          已安装的插件
├── tools/            超分工具二进制
└── watermarks/       可选: 自定义水印 PNG (见下方)
```

`watermarks/` 自定义 (覆盖内置水印样式):

| 文件名 | 对应水印 |
| -------- | ---------- |
| `subtitle.png` | 中字 |
| `uncensored.png` | 无码 |
| `cracked.png` | 破解 |
| `leaked.png` | 流出 |
| `4k.png` / `8k.png` | 4K / 8K |
| `1080p.png` 等 | 其它分辨率 (无内置图标) |

## 应用配置

应用配置通过 Web 界面「设置」页面实时修改, 无需重启.

### 刮削配置 (`scraping`)

见 [刮削指南](scraping.md#刮削设置).

### 水印 (`watermark`)

整理时添加到封面/海报:

- **启用水印**: 是否添加
- **水印大小**: 相对图片高度的比例. 封面和海报通常同高, 水印会一样大
- **水印位置**: 中字 / 无码 / 破解 / 流出 / 分辨率各自选四角之一. 同角按顺序向内叠

### 演员刮削 (`actor_scraping`)

控制演员元数据的获取行为, 详细说明见 [刮削指南 - 演员刮削](scraping.md#_11).

### 网络配置 (`network`)

- **代理**: SOCKS/HTTP 代理 URL (如 `socks5://127.0.0.1:7890`)
- **超时**: HTTP 请求超时时间
- **重试**: 请求的最大重试次数, 不含首次请求 (3 表示最多发 4 次请求, 0 表示只发一次)
- **限速**: 全局和按域名的请求速率限制

### 任务引擎 (`worker`)

- **并发数**: 最大并发任务执行数 (默认 10)

### 文件监控 (`watcher`)

- **轮询模式**: 在 NAS/NFS/Docker Desktop/WSL2 等场景下使用轮询替代原生事件. 只作用于文件监控为「本地文件」的库; CD2 webhook 见 [媒体库管理](libraries.md)
- **防抖窗口**: 文件变动后等待的时间, 避免重复触发; CD2 webhook 目录 create 后的子树扫描也使用该窗口
- **媒体扩展名**: 监控的文件类型白名单

### AI 助理 (`agent`)

- **API 类型**: 支持 OpenAI Chat / OpenAI Response / Anthropic
- **API 密钥**: 对应提供商的密钥
- **模型**: 使用的模型名称
- **思考强度**: 推理深度 (off / minimal / low / medium / high / xhigh)

### LLM 翻译 (`llm`)

- **启用**: 是否启用 LLM 翻译
- **翻译字段**: 需要翻译的字段 (title / plot)
- **API 类型**: 支持 OpenAI Chat / OpenAI Response / Anthropic
- **API 配置**: 端点和密钥
- **自定义提示词**: 替换内置系统提示词的指令部分; 留空使用内置
- **字段提示词**: 逐字段覆盖内置字段说明; 留空使用内置

自定义提示词与字段提示词均可用 `{target_lang}` 引用目标语言名 (简体中文 / 繁體中文 / 日本語 / English). 单条上限 2000 字符. 提示词变化后缓存的旧译文自动失效, 详见 [刮削指南](scraping.md).

### 图像超分 (`sr`)

- **启用**: 刮削时是否自动超分低清图片
- **尺寸阈值**: 最长边小于此值才超分
- **预设**: waifu-photo-2x (默认) 或 realesr-photo-4x

### 通知 (`notify`)

一批任务跑完后, 向钉钉群发一条汇总: 本次处理影片数、成功数、失败数, 并列出前 10 部失败影片及原因. 在群里添加「自定义机器人」后填写:

- **启用钉钉通知**: 总开关
- **Webhook 地址**: 机器人的完整地址 (`https://oapi.dingtalk.com/robot/send?access_token=...`)
- **加签密钥**: 安全设置选「加签」时填 `SEC` 开头的密钥; 否则留空
- **关键词**: 安全设置选「自定义关键词」时填写, 汇总会带上该词; 否则留空
- **静默秒数**: 最后一个结果出现后再等这么久, 且任务队列已空, 才发送
- **最长等待分钟**: 队列一直不空时, 一批最久攒这么久就发送
- **走代理**: 是否使用网络配置中的代理访问钉钉

保存配置时, 若钉钉相关项有变化, 会发一条测试消息; 失败只写日志, 不阻止保存. 统计只含刮削与整理结果, 一部影片以最后一次结果为准.

### Emby 头像同步 (`emby`)

Emby / Jellyfin 的演员头像存在它自己的库里, 不随影片 NFO 更新, 也常常因为无法访问外网而下载失败. 本功能把 amane 已下载到本地的头像直接上传给 Emby 里**还没有头像**的演员, Emby 不需要访问外网.

- **启用**: 总开关
- **服务器地址**: Emby 的访问地址, 如 `http://192.168.1.10:8096`
- **API 密钥**: Emby 控制台 → 高级 → API 密钥 → 新建
- **同步间隔**: 自动同步的间隔; 每轮只处理仍缺头像的演员
- **批次完成后自动同步**: 一批刮削 / 整理做完 (任务队列清空且静默约 1 分钟) 后, 自动通知 Emby 扫描媒体库, 等待下面的分钟数再同步头像. 会让 Emby 刷新整个库, 库很大时它会忙一阵; 不想要就关闭
- **扫描等待时间**: 通知 Emby 扫描后等多少分钟再同步, 默认 3. 演员要先被 Emby 扫描入库才存在, 来不及的由周期同步补上
- **使用代理**: Emby 通常在内网, 一般关闭

保存设置后会立刻同步一次. 演员要先被 Emby 扫描入库才存在, 所以先让 Emby 扫完媒体库, 之后的周期同步会补上. 只有 amane 里已经有头像的演员才会上传, 没有的先做演员刮削. 也可以在左侧「演员」页右上角点「同步演员头像」手动触发, 弹窗里可以选 Emby 媒体库 (留空 = 整个 Emby) 和方式: 「只补缺失」只给没有头像的演员上传, 「覆盖已有」连已有头像的也替换 (周期自动同步固定为整个 Emby、只补缺失). 结果里会列出 amane 无本地头像、amane 里没有该演员、上传失败的演员名, 便于排查; 按库同步取自该库影片的演员表. 接口为 `GET /api/emby/libraries` 与 `POST /api/emby/sync-actors`.

### r18 数据源 (`r18`)

r18.dev 提供 PostgreSQL dump, 需要自备 PostgreSQL 实例:

- **DSN**: 超级用户连接串 (需 CREATEDB/CREATEROLE 权限)
- **下载地址**: dump 归档下载 URL
- **数据库名**: 目标数据库名
